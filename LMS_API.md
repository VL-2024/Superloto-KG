# ЧҮКӨ — обмен игры с LMS (v20)

## 1. Покупка билета / запуск реального раунда

Игра использует формат, переданный разработчиком LMS:

```http
GET https://dev.superloto.kg/api/Lotto.Users.cls?Method=PayTicket&gameId=137&amount=15
```

Параметры:

- `Method=PayTicket` — метод LMS.
- `gameId` — числовой ID игры в LMS. Значение **не зашивается в игру**: LMS передаёт его при запуске игры в URL, например `?gameId=137`.
- `amount` — выбранный игроком номинал/стоимость билета.

В реальном режиме игра не рассчитывает выигрыш самостоятельно. После `PayTicket` она только визуализирует результат, который вернул LMS.

## 2. Минимальный ответ PayTicket для ЧҮКӨ

```json
{
  "ticketId": "123456789",
  "scenario": 3,
  "win": 30,
  "balance": 1240
}
```

Дополнительно LMS может вернуть:

```json
{
  "denomination": 15,
  "currency": "KGS",
  "currencyDisplay": "сом",
  "multiplier": 2
}
```

Обязательные для игры поля:

- `ticketId` — ID/номер созданного билета;
- `scenario` — сценарий анимации `1..5`;
- `win` — сумма выигрыша;
- `balance` — баланс игрока после покупки билета и начисления выигрыша.

Сценарии:

- `1` — ничего не выбито;
- `2` — выбито 1 чүкө;
- `3` — выбито 2 чүкө;
- `4` — выбито 5 чүкө;
- `5` — выбито 5 чүкө + ХАН.

## 3. Данные, которые LMS передаёт при запуске игры

При загрузке игры LMS передаёт настройки через `X2_LMS_INIT`:

```js
iframe.contentWindow.postMessage({
  type: 'X2_LMS_INIT',
  gameId: 137,
  language: 'RU',
  currency: 'KGS',
  currencyDisplay: 'сом',
  denominations: [15, 30, 50],
  denomination: 15,
  balance: 1255,
  mode: 'real',
  demoAllowed: true,
  demoBalance: 10000
}, '*');
```

Язык и валюту игрок внутри игры не меняет. Они используются для локализации интерфейса и отображения обозначения валюты.

Текущий баланс рекомендуется передавать сразу в `X2_LMS_INIT`; тогда отдельный запрос баланса игре не нужен.

## 4. DEMO / REAL

- `mode: 'real'` — реальная игра, используется `PayTicket`.
- `mode: 'demo'` — демонстрационный режим, реальные запросы `PayTicket` не отправляются.
- `demoAllowed: true/false` — разрешает или запрещает игроку переключатель REAL/DEMO внутри игры.

## 5. Кнопка `+` возле баланса

Игра не делает запрос на пополнение сама. При нажатии `+` она отправляет родительской LMS сообщение:

```js
{
  source: 'X2_CHUKO',
  type: 'X2_GAME_DEPOSIT_REQUEST',
  gameId: 137,
  mode: 'real',
  currency: 'KGS',
  denomination: 15,
  language: 'RU',
  balance: 1255
}
```

После этого LMS сама открывает свою страницу/форму пополнения баланса.

## 6. Тестовая сборка GitHub

По умолчанию публичная сборка остаётся в `mock`-режиме, чтобы игра открывалась без LMS.

Для интеграционного запуска LMS может использовать `mock=false` в URL и передать `X2_LMS_INIT`.
